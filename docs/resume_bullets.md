# Resume Bullets

Use one or two of these bullets on your resume, depending on the role.

## AI Agent / LLM Engineer

- Built a multi-agent literature review system that retrieves academic papers, screens relevance, synthesizes themes, identifies research gaps, and generates a structured reading path.
- Implemented a modular agent pipeline with shared state, optional LangGraph orchestration, Groq-backed LLM calls, and deterministic fallback execution for reliable demos.

## Software Engineer

- Refactored an academic AI prototype into a maintainable Python package with a `src/` layout, CLI interface, tests, JSON export, and offline sample-data mode.
- Added resilient retriever integrations for arXiv and Semantic Scholar with deduplication, rate-limit handling, and structured evaluation metrics.

## Data / Research Engineer

- Designed lightweight evaluation metrics for agentic literature review workflows, including retrieval coverage, relevance distribution, source diversity, and pipeline completion.
- Created reproducible demo outputs for research workflow analysis without depending on live APIs or private credentials.
